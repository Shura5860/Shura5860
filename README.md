## Featured Projects

### [AIFuzzer](https://github.com/Shura5860/aifuzzer)
Open-source gray-box fuzzer for LLMs and AI agents.
- Quality-diversity search (MAP-Elites, 54 niches) with bandit-based scheduling and delta debugging for minimal attack inputs
- Findings mapped to OWASP LLM Top 10 (2025) and NIST AI RMF
- Deterministic canary oracles and embedding-distance scoring; TF-IDF + DBSCAN clustering of results
- GitHub Action and Docker support for CI integration
- Stack: Python, Rust, gRPC, SQLite

### [AURA-CORE](https://github.com/Shura5860/LocalAIProject)
Fully local AI assistant: your data never leaves the machine.
- Local inference with Qwen 2.5 Coder models (GGUF, llama.cpp)
- ReAct agent loop with human-in-the-loop approval and guardrails for file, terminal, and web tools
- In-process vector search engine written in Rust (HNSW graph + write-ahead log), exposed to Python via PyO3
- FastAPI backend and a Tauri 2.0 desktop interface
- Stack: Rust, Python, Tauri

### [CineNyx](https://github.com/Shura5860/CineNyx)
Full-stack streaming platform with player, catalog, and admin panel.
- Multi-audio and subtitle support, resume playback, JWT-based sessions
- Media stored on AWS S3 and served through time-limited presigned URLs; chunked uploads
- Automatic metadata import from TMDB
- Stack: Angular (TypeScript), Node.js (Express), MongoDB, AWS S3
